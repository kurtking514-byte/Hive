3.2 Arithmetic Operations
Adding, subtracting, multiplying, and dividing in binary, octal, and hexadecimal

FOUR (4) ARITHMETIC OPERATIONS
★ The four operations are Addition (+), Subtraction (-), Multiplication (*), and Division (/).
EASIER: The steps are the same ones you use in decimal. The only change is the size of the base. A carry or a borrow is worth the base: 2 in binary, 8 in octal, 16 in hexadecimal, and 10 in decimal.
Tip: to check any answer, convert the numbers to decimal, do the operation there, and compare.

ADDITION
★ Adding numbers in different bases means adding corresponding digits right to left.
Carry to the next place value when the sum reaches or exceeds the base.
The process is similar across number systems. Be aware of when and what to carry.
EASIER: Work column by column from right to left. A carry happens when the column total is too large for one digit in that base.
EASIER: Think of an odometer. When a wheel reaches the base, it rolls back to 0 and pushes the next wheel up by 1.
⚙ Step 1: Align the rightmost digits so matching place values sit in the same column.
⚙ Step 2: Add the digits in one column, starting from the right, plus any carry from the column before.
⚙ Step 3: If the column sum equals or exceeds the base, deduct the base from the column sum.
⚙ Step 4: Repeat until what is left is less than the base.
⚙ Step 5: Write what is left in that place value.
⚙ Step 6: Carry the number of base deductions to the next place value.
⚙ Step 7: Repeat until there are no place values left.
⚙ Step 8: Discard any overflown bits, meaning digits that do not fit in the fixed width of the system.

BINARY ADDITION
Decimal positional weights are 10⁰, 10¹, 10². A carry occurs when a column sum reaches the base (10).
★ Binary uses base 2. Binary positional weights are 2⁰, 2¹, 2², 2³.
★ Any sum greater than 1 requires a carry.
⚙ 0 + 0 = 0 (carry 0)
⚙ 0 + 1 = 1 (carry 0)
⚙ 1 + 0 = 1 (carry 0)
⚙ 1 + 1 = 0 (carry 1), because 1 + 1 = 2, which is 10 in binary
⚙ Added rule: 1 + 1 + 1 = 1 (carry 1), when a carry comes into a column that already has 1 + 1.
EXAMPLE: 1011 + 1101
⚙ Column 0 (rightmost): 1 + 1 = 2, write 0, carry 1
⚙ Column 1: 1 + 0 + 1 (carry) = 2, write 0, carry 1
⚙ Column 2: 0 + 1 + 1 (carry) = 2, write 0, carry 1
⚙ Column 3: 1 + 1 + 1 (carry) = 3, write 1, carry 1
⚙ Column 4: only the carry 1 is left, write 1
⚙ Answer: 1011 + 1101 = 11000
⚙ Check: 11 + 13 = 24, and 11000 = 16 + 8 = 24 ✓
EXAMPLE: DISCARDING OVERFLOW IN 4 BITS
⚙ Added example: 1100 + 0110 = 1 0010. The answer has 5 digits.
⚙ A 4-bit system keeps only 4 bits, so discard the leftmost 1 and keep 0010.
⚙ Check: 12 + 6 = 18, and 18 − 16 = 2 = 0010 ✓
⚙ Practice (answer included): 10110 + 1011 = 100001. Check: 22 + 11 = 33, and 100001 = 32 + 1 = 33 ✓

OCTAL ADDITION
★ Octal uses base 8. Digits range from 0 to 7.
If a digit sum exceeds 7, convert it into carry and sum values. A sum of 8 or greater generates a carry of 1.
Values like 8, 9, etc. are not valid single digits in base 8.
★ Formula: Sum = (Carry × 8) + Remainder.
EASIER: In base 8, each single digit can only be 0 through 7. A total of 8 becomes 10 (base 8): write 0 and carry 1.
EXAMPLE: 243 + 212 (NO CARRIES)
⚙ Column 0: 3 + 2 = 5
⚙ Column 1: 4 + 1 = 5
⚙ Column 2: 2 + 2 = 4
⚙ Answer: 243 + 212 = 455 (base 8). No sum exceeds 7.
EXAMPLE: 567 + 243 (WITH CARRIES)
⚙ Column 0: 7 + 3 = 10. 10 = 1×8 + 2, so write 2, carry 1
⚙ Column 1: 6 + 4 + 1 (carry) = 11. 11 = 1×8 + 3, so write 3, carry 1
⚙ Column 2: 5 + 2 + 1 (carry) = 8. 8 = 1×8 + 0, so write 0, carry 1
⚙ Column 3: only the carry 1 is left, write 1
⚙ Answer: 567 + 243 = 1032 (base 8)
⚙ Check: 567 (base 8) = 375, 243 (base 8) = 163, 375 + 163 = 538, and 1032 (base 8) = 512 + 24 + 2 = 538 ✓

HEXADECIMAL ADDITION
★ Hexadecimal uses base 16. Digits are 0-9 and letters A-F.
★ Hex letter values: A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
Hexadecimal uses 16 distinct digits.
If a digit sum equals or exceeds 16, generate a carry.
⚙ Divide the sum by 16. The quotient becomes the carry. The remainder becomes the new digit.
EASIER: In base 16, digits 0-9 are followed by A-F, representing 10-15. A total of 16 or more creates a carry, because one digit can hold only 0-15.
EXAMPLE: 5689 + 4574 (NO CARRIES)
⚙ Column 0: 9 + 4 = 13, which is D
⚙ Column 1: 8 + 7 = 15, which is F
⚙ Column 2: 6 + 5 = 11, which is B
⚙ Column 3: 5 + 4 = 9
⚙ Answer: 5689 + 4574 = 9BFD (base 16). This example has no carries, because no column reached 16.
⚙ Check: 5689 (base 16) = 22153, 4574 (base 16) = 17780, and the sum is 39933 = 9BFD (base 16) ✓
EXAMPLE: DA + DA (WITH CARRIES)
⚙ Column 0: A + A = 10 + 10 = 20. 20 = 1×16 + 4, so write 4, carry 1
⚙ Column 1: D + D + 1 (carry) = 13 + 13 + 1 = 27. 27 = 1×16 + 11, so write B, carry 1
⚙ Column 2: only the carry 1 is left, write 1
⚙ Answer: DA + DA = 1B4 (base 16)
⚙ Check: DA = 218, 218 + 218 = 436, and 1B4 = 256 + 176 + 4 = 436 ✓

SUBTRACTION
★ Subtracting numbers in different bases means subtracting corresponding digits right to left.
★ Minuend: the top number. Subtrahend: the bottom number being subtracted.
Borrow from the next place value when the subtrahend digit is larger than the minuend digit above it.
The process is similar across number systems. Be aware of when and how much to borrow.
EASIER: Borrow only when the top digit is too small to subtract the bottom digit. The borrowed amount equals the base.
EASIER: Borrowing 1 from the next column to the left gives you the base in the current column, like trading one ten-dollar bill for ten ones.
⚙ Step 1: Align the rightmost digits so matching place values sit in the same column.
⚙ Step 2: Subtract the digits in one column, starting from the right.
⚙ Step 3: If the subtrahend digit is larger than the minuend digit, borrow 1 from the next place to the left.
⚙ Step 4: The borrowed 1 has the value of the base. Add the base to the lacking minuend digit.
⚙ Step 5: If the place you want to borrow from is zero, borrow from the next place to its left.
⚙ Step 6: Repeat until 1 is borrowed from a non-zero place value.
⚙ Step 7: Write the difference in that place value.
⚙ Step 8: Note the new values of the places you borrowed from, each one is now smaller by 1.
⚙ Step 9: Repeat until there are no place values left.

BINARY SUBTRACTION
★ When borrowing in binary, borrow 2 (in decimal) rather than 1.
A higher-order bit shifts a value of 2 into the current position.
EASIER: Binary has base 2, so borrowing 1 means adding 2 to the current position. This is why a borrowed binary 1 has a value of 2 (in decimal).
⚙ Binary subtraction rules: 0 − 0 = 0, 1 − 0 = 1, 1 − 1 = 0, and 0 − 1 needs a borrow (borrow 2, so 2 − 1 = 1).
EXAMPLE: 11011 − 10110
This is 27 − 22 in decimal.
⚙ Column 0: 1 − 0 = 1
⚙ Column 1: 1 − 1 = 0
⚙ Column 2: 0 − 1 is not possible. Borrow from column 3, which has 1 and becomes 0. Column 2 becomes 2. Then 2 − 1 = 1
⚙ Column 3: now 0 − 0 = 0
⚙ Column 4: 1 − 1 = 0
⚙ Answer: 11011 − 10110 = 00101, which is 5 in decimal ✓
EXAMPLE: 1110 − 111
This is 14 − 7 in decimal. Write 111 as 0111 so the columns line up.
⚙ Column 0: 0 − 1 is not possible. Borrow from column 1, which has 1 and becomes 0. Column 0 becomes 2. Then 2 − 1 = 1
⚙ Column 1: now 0 − 1 is not possible. Borrow from column 2, which has 1 and becomes 0. Column 1 becomes 2. Then 2 − 1 = 1
⚙ Column 2: now 0 − 1 is not possible. Borrow from column 3, which has 1 and becomes 0. Column 2 becomes 2. Then 2 − 1 = 1
⚙ Column 3: now 0 − 0 = 0
⚙ Answer: 1110 − 111 = 0111, which is 7 in decimal ✓
EXAMPLE: PRACTICE 1111 − 1101 ANSWERED
⚙ Column 0: 1 − 1 = 0
⚙ Column 1: 1 − 0 = 1
⚙ Column 2: 1 − 1 = 0
⚙ Column 3: 1 − 1 = 0
⚙ Answer: 1111 − 1101 = 0010, which is 2 in decimal. Check: 15 − 13 = 2 ✓ No borrowing was needed.

OCTAL SUBTRACTION
★ When the minuend digit is smaller than the subtrahend digit, borrow from the next position.
★ In octal, the borrowed value is 8. This is the base, unlike 10 in the decimal system.
EASIER: A borrowed 1 in base 8 adds 8 to the current digit. This works like borrowing 10 in the decimal system.
EXAMPLE: 743 − 564 (BASE 8)
⚙ Column 0: 3 − 4 is not possible. Borrow from column 1, which has 4 and becomes 3. Column 0 becomes 3 + 8 = 11. Then 11 − 4 = 7
⚙ Column 1: now 3 − 6 is not possible. Borrow from column 2, which has 7 and becomes 6. Column 1 becomes 3 + 8 = 11. Then 11 − 6 = 5
⚙ Column 2: now 6 − 5 = 1
⚙ Answer: 743 − 564 = 157 (base 8)
⚙ Check: 743 (base 8) = 483, 564 (base 8) = 372, 483 − 372 = 111, and 157 (base 8) = 64 + 40 + 7 = 111 ✓

MULTIPLICATION
★ Multiplying numbers in different bases means multiplying each multiplier digit by the multiplicand.
Multiply from right to left. Add correctly aligned partial products for the final product.
The process is similar across number systems. Be aware of when and how much to carry.
★ Multiplicand: the number being multiplied. Multiplier: the number you multiply by.
EASIER: Multiply the way you do in school. For each digit of the multiplier, make one row (a partial product). Shift each new row one place left. Add the rows.
EASIER: Put a 0 (some people use a cross mark) at the right end of each new row to push it one place left. Do this when you move to a higher place.
⚙ Step 1: Align the rightmost digits and corresponding place values.
⚙ Step 2: Multiply the first multiplier digit by each multiplicand digit, from the right.
⚙ Step 3: If a product exceeds the base, deduct the base from it. That is the same as dividing by the base.
⚙ Step 4: Repeat until what is left is less than the base.
⚙ Step 5: Write what is left in that place value.
⚙ Step 6: Carry the number of base deductions to the next place value.
⚙ Step 7: Multiply the same multiplier digit by the next multiplicand digit, and add the carried value to the product.
⚙ Step 8: Repeat steps 4 to 7 until all multiplicand digits have been used.
⚙ Step 9: Repeat the process for each multiplier digit.
⚙ Step 10: Align each partial product with its multiplier digit's place value.
⚙ Step 11: Add all partial products for the final product.

BINARY MULTIPLICATION
★ Binary multiplication rules: 0 × 0 = 0, 0 × 1 = 0, 1 × 0 = 0, and 1 × 1 = 1.
Binary positional weights: 2⁰, 2¹, 2², …
EASIER: In binary, each row is either a copy of the multiplicand (when the multiplier digit is 1) or all zeros (when the multiplier digit is 0).
EXAMPLE: 110 (BASE 2) × 11 (BASE 2)
110 (base 2) = 6 in decimal. 11 (base 2) = 3 in decimal.
⚙ Step 1: multiplier digit in column 0 is 1, so the first row is 110.
⚙ Step 2: multiplier digit in column 1 is 1, so the second row is 110 shifted one place left: 1100.
⚙ Step 3: align the rows by weight: 0110 and 1100.
⚙ Step 4: add using binary addition: 110 + 1100 = 10010.
⚙ Answer: 110 × 11 = 10010 (base 2)
⚙ Check: 6 × 3 = 18, and 10010 = 16 + 2 = 18 ✓
Convert binary numbers to decimal to verify results. This reduces errors with large binary strings.
For exams, direct multiplication can skip weight calculations. Correct alignment of bits is still required before final addition.

Results must remain within the valid octal range (0-7) in each place.
Multiplication follows standard methods using base 8.
EASIER: When a product is too large for one octal digit, use a carry. The remainder stays in the current position; the quotient moves to the next.
⚙ Example of the idea: 14 (base 10) is represented as 16 (base 8), because 1 × 8 + 6 = 14.
⚙ If a product exceeds 7, divide by 8. The remainder is the digit to write. The quotient is the carry to the next column.

DIVISION
★ Dividing numbers in different bases means dividing the dividend by the divisor from left to right.
★ Dividend: the number being divided. Divisor: the number you divide by. Quotient: the answer. Remainder: what is left over.
The process is similar across number systems. Use the traditional long method of division.
EASIER: Start from the left side of the dividend and determine each quotient digit. Subtract the partial result, then continue with the next digit.
⚙ Step 1: Divide the dividend by the divisor, digit by digit, starting from the left.
⚙ Step 2: Calculate each quotient digit.
⚙ Step 3: Subtract the partial result to get the partial remainder.
⚙ Step 4: Bring down the next digit. This is the same as multiplying the remainder by the base and adding the next digit.
⚙ Step 5: Repeat until all digits are used. For fraction digits, keep bringing down 0s until the desired accuracy is achieved.

BINARY DIVISION
Review example in decimal: 128 ÷ 8.
⚙ 12 ÷ 8 = 1, remainder 4. Write 1.
⚙ Bring down the 8 to make 48. 48 ÷ 8 = 6, remainder 0. Write 6.
⚙ Answer: 128 ÷ 8 = 16
Binary division applies the same long-division steps.
EXAMPLE: 101010 (BASE 2) ÷ 110 (BASE 2)
⚙ Take leftmost bits until the number is at least the divisor 110 (6). 1, 10, and 101 (5) are too small. 1010 (10) is big enough.
⚙ 1010 ÷ 110 = 1. Write 1. Subtract: 1010 − 110 = 100.
⚙ Bring down the next bit (1) to make 1001 (9). 1001 ÷ 110 = 1. Write 1. Subtract: 1001 − 110 = 011.
⚙ Bring down the last bit (0) to make 0110 (6). 110 ÷ 110 = 1. Write 1. Subtract: 110 − 110 = 000.
⚙ Quotient digits: 1, 1, 1. Remainder: 0.
⚙ Answer: 101010 ÷ 110 = 111 (base 2)
Verify by converting the numbers to decimal: 42 ÷ 6 = 7. The binary quotient is 111 (base 2).

OCTAL DIVISION
★ Octal division uses base 8.
Integer division can use a reference chart of multiples. The chart simplifies the subtraction process.
Octal long division mimics standard decimal long division. Borrowing from a higher column adds 8 instead of 10.
Create a multiplication table for the divisor beforehand. This helps manage octal calculations and avoid errors.
EASIER: A divisor multiplication table helps you quickly choose each quotient digit.
EXAMPLE: 1104 (BASE 8) ÷ 12 (BASE 8)
⚙ Added example: multiples of the divisor 12 (base 8): 12 × 1 = 12, 12 × 2 = 24, 12 × 3 = 36, 12 × 4 = 50, 12 × 5 = 62, 12 × 6 = 74, 12 × 7 = 106
⚙ Take leftmost digits until the number is at least 12. 1 and 11 are too small. 110 is big enough.
⚙ The biggest multiple not above 110 is 106 (× 7). Write 7. Subtract: 110 − 106 = 2.
⚙ Bring down the 4 to make 24. 24 is exactly 12 × 2. Write 2. Subtract: 24 − 24 = 0.
⚙ Answer: 1104 ÷ 12 = 72 (base 8), remainder 0
⚙ Check: 580 ÷ 10 = 58, and 72 (base 8) = 56 + 2 = 58 ✓
Fractional octal division involves decimal points (octal points).
⚙ Step 1: Shift decimal points to clear them from divisor and dividend. Temporarily remove the decimal points.
⚙ Step 2: Perform standard octal long division.
⚙ Step 3: Re-insert the decimal point based on the original positions. Adjust the quotient afterward.
EASIER: For fractional values, remove decimal points first, then restore them afterward.
⚙ Added example: 12.4 ÷ 2 (base 8). Remove the point: 124 ÷ 2. 12 ÷ 2 = 5 (since 12 (base 8) = 10 and 10 ÷ 2 = 5), remainder 0. Bring down 4: 4 ÷ 2 = 2. Quotient 52.
⚙ Re-insert the point where it was in the dividend, one digit from the right: 5.2 (base 8).
⚙ Check: 12.4 (base 8) = 10.5, 10.5 ÷ 2 = 5.25, and 5.2 (base 8) = 5 + 2/8 = 5.25 ✓
⚙ Added example: when both numbers have points, shift both by the same amount. 1.6 ÷ 0.2 (base 8) becomes 16 ÷ 2 = 7 (base 8), since 16 (base 8) = 14 and 14 ÷ 2 = 7. The quotient stays 7.
⚙ Check: 1.6 (base 8) = 1.75, 0.2 (base 8) = 0.25, and 1.75 ÷ 0.25 = 7 ✓

HEXADECIMAL DIVISION
EXAMPLE: B41F (BASE 16) ÷ A (BASE 16)
⚙ SETUP: A = 10 and B = 11 in decimal.
⚙ Step 1: Determine how many times A goes into B (or 11 (base 10)). The quotient digit is 1 and the remainder is 1.
⚙ Step 2: Bring down 4 to work with 14 (base 16), which is 20 (base 10). A goes into 20 exactly twice. The quotient digit is 2 and the remainder is 0.
⚙ Step 3: Bring down 1 to work with 01, which is 1. A does not go into 1, so the quotient digit is 0 and the remainder is 1.
⚙ Step 4: Bring down F to work with 1F (base 16), which is 31 (base 10). A goes into 31 three times (30), so the quotient digit is 3 and the remainder is 1.
⚙ Convert values such as 1F (base 16) = 31 (base 10) to complete the calculation.
⚙ Final result: 1203 with a remainder of 1 in base 16.
⚙ Check: B41F (base 16) = 46111, and 46111 ÷ 10 = 4611 remainder 1. 1203 (base 16) = 4096 + 512 + 3 = 4611 ✓
EXAMPLE: A FRACTIONAL HEX QUOTIENT
⚙ Added example: 1 ÷ 2 (base 16). 2 does not go into 1, so the whole part is 0, remainder 1.
⚙ Multiply the remainder by the base: 1 × 16 = 16, which is 10 (base 16). Now 16 ÷ 2 = 8, remainder 0.
⚙ Answer: 0.8 (base 16). Check: 8/16 = 0.5 ✓

COMMON MISTAKES
Do not carry or borrow 10 in other bases. Carry and borrow the base: 2, 8, or 16.
Do not forget to carry when a column equals the base exactly. For example, 8 in octal is 10 (base 8).
Do not use the digits 8 or 9 in octal, or letters beyond F in hexadecimal.
Do not forget to shift each new row of a multiplication one place left.
Do not forget to subtract 1 from the place you borrowed from.
Always check by converting to decimal.
